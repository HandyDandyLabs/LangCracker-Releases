# LangCracker-Releases

Official release builds and distribution archive for **LangCracker** — a free, offline-first, real-time global media translator built for Android. 

LangCracker is designed to handle all your media translation needs without requiring an internet connection.

## ✨ Key Features
* **Real-Time Subtitle Translation:** Translate video subtitles in any language on the fly to the language of your choice.
* **Manga & Comic Page Translator:** Built-in OCR and translation tailored for manga, manhwa, and comic book pages.
* **Offline Audio Translator:** Transcribe and translate spoken audio in real time.
* **100% Offline-First & Free:** Works without active internet access, keeping your media private and accessible anywhere.
* **Keeps Ads FAR off!** We know it's frustrating to break your movie with an ad from a subtitle translator app, so we keep them absolutely away!

## 📥 How to Download & Install
1. Go to the **[Releases](../../releases)** section on the right side of this page.
2. Download the latest `.apk` file under **Assets**.
3. Open the downloaded file on your Android device (enable *"Install from unknown sources"* if prompted).

## 📱 Requirements
* **OS:** Android 10+
* **Storage:** App and base version 100MB. [May need additional space for language models of your choice and use cases]
